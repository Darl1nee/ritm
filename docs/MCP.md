# Подключение ИИ-агентов к Ритму (MCP)

Ритм умеет работать с Claude Code, Claude Desktop и другими MCP-клиентами: агент читает и меняет задачи,
проекты, календарь, заметки и цели. Всё, что делает агент, видно в журнале и отменяется одним нажатием.

## 1. Запустите Ритм
`npm run dev` (или `npm start`). Адрес MCP: `http://localhost:3000/api/mcp`.
Облачные клиенты (claude.ai, телефон) пока не подключить — для этого нужны HTTPS и OAuth после деплоя.

## 2. Создайте ключ
Настройки → «ИИ-агенты (MCP)» → «Новый ключ». Задайте имя и права (чтение и запись отдельно для задач,
проектов, календаря, заметок и целей). Ключ показывается один раз — скопируйте его сразу.
Выдавайте минимум прав: агент видит только те инструменты, на которые у ключа есть права.
Ключ можно изменить, отозвать (перестаёт работать сразу) и удалить.

## 3. Подключите клиент

**Claude Code**
```
claude mcp add --transport http ritm http://localhost:3000/api/mcp --header "Authorization: Bearer <ключ>"
```

**Claude Desktop** — в `claude_desktop_config.json` (через мост `mcp-remote`):
```json
{ "mcpServers": { "ritm": { "command": "npx", "args": ["-y", "mcp-remote", "http://localhost:3000/api/mcp", "--header", "Authorization:${RITM_AUTH}"], "env": { "RITM_AUTH": "Bearer <ключ>" } } } }
```
После правки конфига перезапустите Claude Desktop.

## 4. Проверьте
Попросите агента: «Вызови get_context в Ритме» или «Что у меня сегодня по задачам?».
Также есть готовые промпты: `plan_week` (спланировать неделю) и `break_down_project` (разбить проект на задачи).

## Журнал и отмена
Настройки → «Журнал агентов»: каждое действие агента (создание, изменение, удаление) с кнопкой «Отменить».
Отмена восстанавливает прежние значения; удалённое возвращается с теми же данными. Нельзя отменить уже отменённое,
а также действие над объектом, который с тех пор удалён (или, для удаления, уже создан заново).

## Безопасность
- Ключ хранится только в виде хеша; потерянный ключ не восстановить — создайте новый.
- Сервер принимает только запросы с локального адреса и проверяет Host/Origin.
- Удаление проектов, целей и категорий через MCP намеренно не предусмотрено.
- Не публикуйте ключ и не коммитьте его в репозиторий.
